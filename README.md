# el-ultimo-faro
**El Último Faro** es una experiencia de realidad virtual desarrollada en Unity para Meta Quest, ambientada en una isla de Chiloé. Explora un entorno low poly, interactúa con objetos y repara un antiguo faro mientras descubres un misterio inspirado en la Pincoya, el Tué Tué y el Caleuche.
